Purpose #

Capture what’s true before deciding what to build. Everything here should be sourced — from the owner’s provided PDFs, manufacturer documentation, code references, or reputable build guides.

How research flows #

  1. Drop source PDFs into docs/assets/pdf/.
  2. Summarize each into pdf-digests.md, noting the key facts and the file it came from.
  3. Promote decisions/requirements that emerge into 02-planning/ and 03-design/.

Research topics to cover #

  • [ ] Electric heater types & how to size kW to cabin volume.
  • [ ] Wall assembly: insulation, vapor/foil barrier, air gap, cladding.
  • [ ] Best interior wood species for an electric sauna (heat/moisture, low resin).
  • [ ] Ventilation schemes for electric saunas (intake/exhaust placement).
  • [ ] Foundation options for a freestanding outdoor structure.
  • [ ] Weatherproofing / exterior envelope for outdoor exposure.
  • [ ] Electrical requirements (circuit, GFCI, disconnect, local code).
  • [ ] Bench ergonomics and heater clearances.
  • [ ] Door and glass considerations (heat loss vs. feel).
