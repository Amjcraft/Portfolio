Overview #

A buy-list / procurement summary for collecting materials — quantities plus the exact specs to ask suppliers for. Detailed costs and takeoffs live in materials-and-tools.html; this page is the “what to order” sheet. Quantities are preliminary (from the ~9.5 × 8 ft, 2×6 design) — confirm against the measured slab before buying.

All wood: buy kiln-dried (KD). KD stock is dry, straight, and stable — critical in a sauna that cycles hot/humid. Avoid green/wet lumber.

Wood specs — what to order (the important part) #

1. Western Hemlock — walls, ceiling, duckboard (~305 ft² T&G) #

This is the majority of the visible interior. Options to specify when ordering:

Spec Options available Recommended
Drying Kiln-dried (KD) / green Kiln-dried
Profile T&G (tongue-and-groove), nickel-gap, V-groove, shiplap, square-edge T&G, eased or micro-V edge
Grade Clear (C & Btr) / Select / #2 Common (knotty) Clear or Select (few/no knots)
Grain Vertical grain (VG) / flat / mixed VG (most stable, less cupping)
Board width 1×4 (~3½″ face) / 1×6 (~5½″ face) 1×4 (classic sauna look)
Thickness ½″ / ⅝″ / ¾″ ⅝″–¾″
Surfacing S4S / S4S eased edges (S4SEE) S4SEE
End-match end-matched T&G / square ends End-matched (less waste)

Tell the supplier: “Kiln-dried Western Hemlock 1×4 T&G, clear/select vertical grain, S4S eased-edge, end-matched, ~⅝–¾″.” Buy ~10–15% over 305 ft² for waste.

2. Western Red Cedar — bench slats only (~27 × 2×4×8) #

The wood people sit on — spec for comfort and stability:

Spec Options available Recommended
Drying Kiln-dried / green Kiln-dried
Grade Clear VG (A & Btr) / Select Tight Knot (STK) / knotty Clear VG (A & Btr) — no knots/sap
Grain Vertical grain (VG) / flat / mixed VG (bench standard — smooth, stable)
Wood Heartwood / sapwood Heartwood (clear VG is mostly heart)
Size 2×4 (1½×3½) / 5/4 bench board / wide bench board (~5½″) 2×4 VG (matches takeoff)
Surfacing S4S / S4S eased edges (S4SEE) S4SEE (rounded, splinter-free)

Tell the supplier: “Kiln-dried clear vertical-grain Western Red Cedar 2×4, A & better, S4S eased-edge, sauna/bench grade.” Some sell this exact item as “sauna bench material — cedar 2×4 VG S4SEE, clear A+.”

3. Hem-fir — bench frame (~18 × 2×4×8) & wall framing #

Hidden structure — standard framing lumber, no special finish:

Spec Options Recommended
Species/grade Hem-fir Standard & Btr / #2 & Btr Hem-fir #2 & Btr (matches interior species)
Drying KD (S-DRY) / green KD (S-DRY)
Not Pressure-treated No PT indoors (off-gasses when hot)
  • Bench frame: 2×4×8 hem-fir. Wall studs/plates: 2×6 (hem-fir or SPF, KD).
  • SPF is a fine cheaper substitute for any hidden framing if the yard has it lower.

Consolidated shopping checklist #

Grouped for shopping trips. Quantities preliminary; see materials-and-tools.html for detail.

Base / floor (on existing slab) #

  • [ ] PT 2×6×8 floor joists + rims — ~11
  • [ ] ¾″ exterior/PT plywood subfloor — 3 sheets
  • [ ] Waterproof floor finish (membrane + tile, or coating) — ~72 ft²
  • [ ] Floor drain fitting — 1; 2″ Sch-40 PVC (DWV) + fittings + primer/cement — ~15 ft
  • [ ] French drain: perforated pipe + gravel + filter fabric
  • [ ] Capillary break/sill gasket · joist hangers · concrete wedge/epoxy anchors

Framing #

  • [ ] 2×6×10 wall studs — ~34; 2×6×8 plates/blocking — ~15
  • [ ] 2×6×10 shed rafters — ~9; hurricane ties, rafter/joist hardware
  • [ ] Construction adhesive — 2 tubes

Sheathing & envelope #

  • [ ] OSB/ply 7/16″ sheathing — ~13 sheets (10 wall + 3 roof)
  • [ ] House wrap — 1 roll · roofing underlayment — 1 roll
  • [ ] Siding (T1-11 / LP SmartSide) — ~306 ft²
  • [ ] Roofing (metal panel or shingle) — ~1 square · drip edge / flashing / trim

Insulation & vapor barrier #

  • [ ] Mineral wool batts R-23 (2×6) — ~7–8 bags
  • [ ] Foil vapor barrier (sauna foil) — ~370 ft² · foil tape — 2–3 rolls

Interior (the wood above) #

  • [ ] Hemlock 1×4 T&G — ~305 ft² (+waste)
  • [ ] Furring/battens (air gap) — ~200 lf
  • [ ] Clear VG cedar 2×4×8 (bench slats) — ~27
  • [ ] Hem-fir 2×4×8 (bench frame) — ~18
  • [ ] Duckboard — built from hemlock stock
  • [ ] Sauna paraffin oil — 1

Openings & ventilation #

  • [ ] DIY door: hemlock panel stock + large tempered-glass lite + SS hinges + handle + heat-safe gasket
  • [ ] Adjustable vents — 2

Fasteners & hardware #

  • [ ] Stainless screws (interior + bench) · framing screws · ledger lag screws
  • [ ] Concrete anchors · joist/rafter hardware

Deferred — electrical & heater (buy later) #

  • [ ] Electric heater ~9.5 kW + stones · controller/thermostat
  • [ ] Circuit: breaker, 6 AWG cable, disconnect, GFCI — licensed electrician for hookup

Before you buy #

  • [ ] Measure the existing slab; confirm ~9.5 × 8 fits and is square/level.
  • [ ] Get hemlock T&G + cedar bench quotes from local Bend/Portland mills (pricing sheets: [[hemlock-pricing]], [[cedar-pricing]]).
  • [ ] Pick siding (T1-11 vs LP SmartSide) and roofing.
  • [ ] Add ~10–15% waste on boards/paneling.
