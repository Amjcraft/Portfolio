## Overview

This is the deliverable: the comprehensive, ordered, step-by-step guide to building
the sauna. It assembles the decisions made across Research, Planning, and Design
into a sequence a DIYer can follow. **It stays a skeleton until the design docs it
depends on are complete** — each phase links back to its design source.

> **Note:** Don't write build steps whose design isn't settled yet. When a phase's
> design doc reaches `complete`, flesh out that phase here.

## Assembly sequence (outline)

### Phase 0 — Preparation
- Confirm permits, final dimensions, materials, and tools on site.
- Sources: `02-planning/permits-and-code.md`, `materials-and-tools.md`.

### Phase 1 — Foundation
- Build the foundation appropriate to the site.
- Source: `03-design/foundation.md`.

### Phase 2 — Framing & envelope
- Frame floor, walls, roof; sheath and weatherproof the exterior.
- Source: `03-design/framing.md`.

### Phase 3 — Rough electrical
- Run the heater circuit to the sauna (rough-in before insulation).
- Source: `03-design/electrical-and-heater.md`.

### Phase 4 — Insulation & vapor barrier
- Mineral wool in bays; continuous taped foil barrier across walls + ceiling.
- Source: `03-design/insulation-and-vapor-barrier.md`.

### Phase 5 — Interior cladding
- Battens/air gap, then cladding on walls and ceiling.
- Source: `03-design/interior-cladding.md`.

### Phase 6 — Ventilation
- Install and adjust intake/exhaust vents.
- Source: `03-design/ventilation.md`.

### Phase 7 — Benches, floor, door, lighting
- Duckboard/floor, benches, sauna door, heat-safe lighting.
- Source: `03-design/benches-and-interior.md`.

### Phase 8 — Heater install & final electrical
- Mount heater, set clearances, load stones, final connection + inspection.
- Source: `03-design/electrical-and-heater.md`.

### Phase 9 — First fire & commissioning
- Initial burn-in per heater manual, check ventilation, verify safety.
