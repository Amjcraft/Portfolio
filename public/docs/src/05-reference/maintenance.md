## Overview

Keeping the finished sauna safe, clean, and long-lived. Populated near the end of
the project, but captured here as decisions imply upkeep.

## Routine

- **After each use:** open vents/door to dry the room; wipe benches.
- **Periodically:** clean cladding with mild solution; re-oil benches if using sauna oil.
- **Stones:** inspect yearly; replace cracked/crumbling stones (they degrade with heat cycles).
- **Heater:** follow manufacturer service intervals; check element and wiring.
- **Envelope (outdoor):** inspect siding/roof/seals seasonally; keep drainage clear.

## Safety checks

- [ ] Test any GFCI on schedule.
- [ ] Verify heater clearances haven't been encroached by added items.
- [ ] Check vents operate freely.
