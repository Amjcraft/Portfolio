## Purpose

Capture what's true before deciding what to build. Everything here should be
sourced — from the owner's provided PDFs, manufacturer documentation, code
references, or reputable build guides.

## How research flows

1. Drop source PDFs into `docs/assets/pdf/`.
2. Summarize each into `pdf-digests.md`, noting the key facts and the file it came from.
3. Promote decisions/requirements that emerge into `02-planning/` and `03-design/`.
