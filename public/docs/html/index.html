The project #

Design and build an outdoor, electric-heater, DIY sauna. This site collects everything — research, planning, design decisions, and the final step-by-step build guide — in one consistently-styled place.

Start here #

  • Overview — the project charter and a glossary of sauna terms.
  • Research — digested findings from provided PDF materials and outside sources.
  • Planning — requirements, site assessment, budget, permits, and materials.
  • Design — the technical decisions: dimensions, foundation, framing, insulation, electrical/heater sizing, ventilation, and interior.
  • Build guide — the comprehensive, ordered assembly instructions (the deliverable).
  • Reference — codes/standards, suppliers, and maintenance.

How the pieces fit #

Decision: Nothing goes into the build guide until the design decision behind it is captured and justified in Planning or Design, which in turn traces back to Research. This keeps the final guide trustworthy and auditable.

Research  →  Planning / Design  →  Build guide
(what's true)  (what we'll do & why)   (how to do it)

Current status #
