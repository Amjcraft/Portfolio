Overview #

A place to record the specific standards, code sections, and manufacturer specifications that govern this build — with the exact citation, so the design and build docs can point here instead of restating them.

Registry #

Ref Applies to Source / citation Notes
— Electrical circuit Local electrical code + heater manual Confirm with AHJ
— Accessory structure permit Local building dept. Size/setback rules
— Heater clearances Manufacturer manual Non-combustible distances
— Foundation / frost depth Local code Region-specific

Note: “AHJ” = Authority Having Jurisdiction (your local building/electrical department). Their word overrides general guidance.
